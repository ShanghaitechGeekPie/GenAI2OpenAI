### Context measurements

Needle-in-a-haystack checks placed a key fact halfway through the input and checked retrieval:

- **deepseek-r1:** passed 100k tokens; returned an empty response at 150k.
- **deepseek-v3, glm-5.1 and minimax-m1:** passed every check from 100k through 200k tokens.
- **qwen3.5-397b-a17b:** returned HTTP 500 at 100k tokens.
- **GPT family:** context checks remained incomplete because Azure quota restrictions produced empty `content` responses. The previous record cited nominal capacities of 1M for GPT-4.1 and 128k–256k for GPT-5/o3; use the provider's current documentation for deployment limits.

These are recorded retrieval results under the available upstream service and token quota. Check a small request against the intended model before a long run; upstream stability and token-specific GPT restrictions can affect results.
