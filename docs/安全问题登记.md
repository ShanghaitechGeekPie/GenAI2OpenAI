# 安全问题登记

本文件只登记当前检查到的问题。本轮核心模块拆分不处理这些问题，也不改变现有安全行为。

## 已登记

| 编号 | 问题 | 现状 | 后续处理方向 |
| --- | --- | --- | --- |
| SEC-001 | 服务默认监听 `0.0.0.0` | 可被同网段访问 | 增加监听地址配置，默认限制为本机 |
| SEC-002 | 缺少代理层独立鉴权 | 请求 token 直接转发上游 | 增加代理层 API key 或访问控制 |
| SEC-003 | CORS 默认全开放 | 使用 `CORS(app)` | 改为可配置来源白名单 |
| SEC-004 | token 明文缓存 | `.genai_token_cache` 保存原文 token | 改用用户私有目录和受限权限，必要时加密 |
| SEC-005 | 图片 URL 可由请求方任意指定 | 服务端直接下载 URL | 增加协议、域名、大小和重定向限制，防止 SSRF |
| SEC-006 | 图片上传缓存无限增长 | 进程内字典没有过期和容量限制 | 增加容量、过期时间和 token 隔离 |
| SEC-007 | 上传 token 硬编码 | CLI 默认值包含固定 token | 改为外部配置或环境变量 |
| SEC-008 | 文档中存在疑似真实凭据示例 | 自动登录 README 含具体账号密码样式字符串 | 替换为纯占位符，并检查历史提交 |
